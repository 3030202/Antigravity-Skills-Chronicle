## 1. 核心定位與願景 (Core Vision)
**「這是你在 VS Code 裡，統御所有 AI 智能體、技能與對話歷史的終極指揮艙。」**

Antigravity: Skills Chronicle 是一款專為重度 AI 開發者與 Prompt 工程師設計的 VS Code 擴充套件。我們不只是一個聊天視窗，而是一個能讓你的 AI「大腦」有紀律地成長的「資產管理中樞」。從 V1 的基礎建設，到 V2 帶來的上帝視角與物理統治，我們正在重新定義人類與多個 AI 專家協作的標準。

---

## 2. 完整功能大盤點 (Features Showcase)

### 🌟 V2.0.0 重磅升級：深層檢索與資產統治 (The V2 Evolutions)

1. **🌌 引力星圖 (Star Map Topology)**
   - **功能**：運用物理引力引擎，將錯綜複雜的 AI 技能、規則與工作流程，化為一張有機的星系拓撲圖。支援雙視圖切換。
   - **賣點**：告別雜亂無章的資料夾！以「上帝視角」看見每一個智能體之間的依賴與連結，拖曳節點時的物理回饋感更是極致的視覺享受。
2. **🔍 歷史觀測站：深層快取檢索 (Deep Full-Text Search)**
   - **功能**：內建增量解析與防抖檢索機制，自動鎖定並展開當下開發專案的歷史。
   - **賣點**：忘記跟 AI 討論過什麼架構？只要輸入關鍵字，瞬間從橫跨數個月的歷史對話中精準撈出記憶。
3. **🛡️ 絕對資料主權：一鍵全域備份 (Batch Export)**
   - **功能**：一鍵攔截並解析系統中所有的加密對話，自動轉換為標準 Markdown 檔案，派發至對應的專案目錄下。
   - **賣點**：你的對話資產不該被鎖死在黑盒子裡。我們實體化您的每一滴知識結晶，讓知識真正屬於您。
4. **⚡ VS Code 原生深度整合 (Activity Bar & Quick Assets)**
   - **功能**：入駐 VS Code 左側工具列 (Activity Bar)，提供 Quick Commands 與本機資產樹狀導航 (TreeView)。
   - **賣點**：現在，啟動儀表板、發動工作流或鑄造新技能，只需要點擊一下側邊欄。效率與沉浸感大幅提升。

### 🏗️ 穩固的 V1 核心基石 (The Base Foundation)

1. **🤖 技能中樞與本機管理 (Skills Hub & Local Management)**
   - 提供專屬的 Dashboard，視覺化管理 `SKILL.md` (AI 人格/技能設定)、`workflows` (標準作業流程 SOP) 與 `rules` (法典與限制)。
2. **🌐 官方公版生態庫 (Official Library)**
   - 一鍵連線至 Antigravity 官方展示庫，瀏覽並下載最新的 A1 系統公用強大技能與規則，讓你的 AI 軍團時刻保持升級。
3. **📝 便捷設定與多語系 (Config & i18n)**
   - 直覺的前端介面配置全域路徑與 API Token。
   - 支援 繁中、簡中、英文、日文、韓文 五大語系無縫切換。
