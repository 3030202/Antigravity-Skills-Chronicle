# Antigravity: Skills Chronicle Project Brief

> 📅 **Created**: 2026-02-22

## 1. 專案目標 (Project Goal)

**Antigravity: Skills Chronicle**
*The premium management layer for AI Skills, powered by the ChronicleCore system.*

本專案旨在打造一個專屬於 ChronicleCore AI 專家系統的 VS Code 擴充套件，提供一個高端、視覺化的管理儀表板。透過賦予開發者管理 AI 團隊的「上帝視角」，讓使用者能夠在編輯器內優雅地統籌與檢視 `.agent/` 目錄下的所有核心資產。

---

## 2. 核心模組 (Core Modules)

1.  **Skills Dashboard (專家管理)**: 檢視與管理 `.agent/skills/` 下的所有 AI 專家定義 (`SKILL.md`)，並提供視覺化的五維圖及金字塔式能力展現。
2.  **Workflow Manager (流程指揮)**: 組織與啟動 `.agent/workflows/` 中的自動化協定 (SOP)。
3.  **Rules Inspector (律法檢閱)**: 檢閱影響 Agent 行為的全局與局部規則 (`.agent/rules/`)。
4.  **Conversation Archive (記憶回溯)**: 瀏覽並搜尋歷史對話紀錄 (`.gemini/conversations/`)，並支援將過往成功經驗提煉為新技能。

---

## 3. 目標用戶 (Target Audience)

- **Who**: 使用 ChronicleCore 專家系統的軟體工程師、AI 架構師與系統開發者。
- **Pain Point**: 開發與管理 AI 專家系統時，缺乏統整性的視覺化介面來快速索引與調試大量散落的 Agent 資產檔案。
- **Desired Outcome**: 能在熟悉的 VS Code 開發環境內，以極致優雅的體驗監控、維護與擴充 AI 專家團隊。
